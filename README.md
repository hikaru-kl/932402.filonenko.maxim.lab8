# Лабораторная работа №8 — Галерея фотографий

Вариант 11. Начальная версия: Express, SQLite и создание альбомов.

## Запуск

```bash
npm install
npm start
```

Откройте `http://localhost:3000`.

## API

- `GET /api/albums`
- `POST /api/albums` с JSON `{"name":"Путешествия"}`
- `GET /api/status`

База `gallery.db` и таблицы `albums`, `photos` создаются автоматически.
